Hébergement et services

  • Cloudflare Pages : hébergement des pages publiques. Service de Cloudflare, Inc., utilisé selon ses conditions d'utilisation.
  • Cloudflare Workers : API de la console d'édition (claude-prime-api), avec R2 (stockage des fiches) et D1 (base SQL), tous deux en juridiction Union européenne.
  • Cloudflare Access : authentification des personnes autorisées à modifier les fiches.
  • Cloudflare Turnstile : vérification anti-robots du formulaire de commentaires. Seule la console d'édition charge son script, depuis challenges.cloudflare.com.

Bibliothèques tierces

  • API (Worker) : aucune dépendance embarquée dans le code mis en ligne.

Les modules facultatifs @img/sharp-libvips-* sont sous LGPL 3.0 : ils servent seulement à l'outil sur l'ordinateur du développeur et ne sont ni intégrés ni distribués avec le site.

Transparence sur l'usage de l'IA

  • Ce site a été réalisé en vibe-coding : le code et une partie des textes ont été produits avec des assistants d'IA (Claude d'Anthropic, ChatGPT d'OpenAI) à partir de consignes rédigées par l'auteur.
  • Le code de l'API (dossier worker/) a été généré en grande partie par Claude, puis relu, testé (tests automatisés) et validé par l'auteur avant chaque mise en ligne.
  • Les choix de structure, de contenu et de mise en ligne sont ceux de l'auteur, qui relit systématiquement ce qui est publié.

Ce refus est aussi exprimé de façon lisible par machine dans le fichier robots.txt.
